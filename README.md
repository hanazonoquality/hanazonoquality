# hanazonoquality 𓂀

> Иркутск // инженер АСУ ТП // исследователь промышленных систем

Этот профиль существует для экспериментов с автоматизацией технологических процессов, промышленной вычислительной техникой и инженерными решениями.

Здесь рождаются прототипы, стенды и инструменты для управления — не ради хаоса, а ради понимания систем.

Проекты могут быть учебными или экспериментальными.

- сохранить возможность безопасного восстановления.
